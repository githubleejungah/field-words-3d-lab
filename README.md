# 필드워드 코드 해석 게임 — "코드 가려 보기"

코드 한 줄을 가리고, 무엇이 달라질지 먼저 맞혀 본 뒤, 가린 코드를 실제로 실행해 확인하며 **코드를 읽는 힘**을 키우는 게임입니다. FDE 실무 용어 앱 [필드워드](https://githubleejungah.github.io/field-words/)에 붙이는 것을 목표로 합니다.

- 지금 상태: **시제품 만드는 중**. 설계 승인(2026-11-22) 뒤 문제 8개(등급마다 2개) · 문제 검사 도구 · 규칙 코드 · 화면(실력 확인 · 오늘 할 일 · 한 판 ①②③ · 착각 다시 풀기 · 도움 판)을 만들었습니다. 질문 보내기는 아직입니다(구글 폼을 만든 뒤).
- 비용: 사용자 · 개발자 모두 0원. 서버 없이 브라우저에서만 돌아가는 정적 사이트로 만듭니다.

## 게임 한 판

| 단계 | 하는 일 |
|---|---|
| ① 해석 보기 | 줄마다 우리말 풀이가 붙은 코드와 실행 장면을 따라가 봄 |
| ② 가려 보기 | 한 줄을 가리고 출력 예측 → 확신도 → 실제 실행 → 원래 출력과 비교 |
| ③ 해석 고르기 | 가린 줄이 하는 일을 떠올린 뒤, 착각을 진단하는 보기 중에서 고름 |

처음 보는 코드는 ①부터, 이미 본 코드는 ②부터 시작합니다. 근거와 자세한 규칙은 [요구 문서](docs/requirements.md)에 있습니다.

## 실행하기

필드워드 저장소와 이 저장소를 같은 폴더(`실습산출물`)에 두고, **그 위 폴더에서** 서버를 띄웁니다. 그래야 필드워드 용어 사전(비유 · 용어 이름)을 함께 읽습니다.

```
cd C:\Users\User\실습산출물
python -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 `http://localhost:8765/field-words-3d-lab/site/` 를 엽니다. 이 저장소 폴더에서 띄워도 게임은 돌아가지만, 비유와 용어 이름이 빠집니다.

- 문제 데이터 · 실전 읽기 검사: `node tools/check_problems.mjs`
- 단위 시험: `node --test tests/`
- 복습 날짜 시험(개발 중에만): 주소 끝에 `?day=2026-11-23` 처럼 날짜를 붙이면 그날로 봅니다.
