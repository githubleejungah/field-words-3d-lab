# ADR-0006: 한 판 끝 보상은 꽃가루 대신 코드 탑(삼층석탑)으로, 효과는 끝 화면에만

> **칸 모양은 [ADR-0008](0008-익히면-황금-벽돌.md)로 대체**(2026-11-25): 익히면 황금 벽돌, 상자 8은 빛나는 황금 벽돌.

- 상태(Status): **채택(Accepted)** — 2026-11-24 설계 초안(석가탑 비례 · 밝은 금색 반영)과 함께 사용자 승인
- 날짜: 2026-11-24
- 결정한 사람: 프로젝트 오너(사용자)가 방향을 정함(요구 Q40 · Q41). Claude가 구조를 제안.

## 1. 배경 (Context)

- 한 판 끝 화면이 결과 이름표 1개와 버튼 2개뿐이라 심심하고 뿌듯함이 없다(Q40). 필드워드처럼 성장이 쌓이는 화면이 필요하되, 게임답게 달라야 한다.
- 꾸밈은 학습을 방해할 수 있다(유혹적 세부 효과, Q24). 학습자 화면은 한 화면에 할 일 하나(Q18).
- 비용 0원 · 외부 라이브러리 0개(AC-01 · 72).

## 2. 선택지 (Options)

| 방법 | 게임다움 | 학습 목표와 맞나 | 판단 |
|---|---|---|---|
| 꽃가루(필드워드와 같음) | △ 필드워드와 같다 | 많이 한 것만 축하 | ❌ 사용자가 다른 것을 원함 |
| 경험치 바 · 레벨 | ○ | ❌ 틀려도 똑같이 쌓인다 | ❌ |
| 문제 도감(카드 모으기) | ○ | △ 이미 푼 문제의 복습에는 보상이 약하다 | ❌ |
| 탑: 답 1번 = 블록 1개 | ○ | ❌ 많이 한 것만 보인다. 끝이 없다 | ❌ |
| **탑: 문제 1개 = 칸 1개, 칸 모양 = 아는 정도. 삼층석탑(기단 + 3층 + 상륜부)** | ○ 가림막을 벗긴 줄이 돌이 된다 | ○ 불안 · 착각 · 장기 기억이 돌 모양으로 보인다 | ✅ 채택 |

## 3. 결정 (Decision)

1. 탑은 삼층석탑 한 기: 입문 = 기단, 기본 · 실무 · 심화 = 탑신 1 · 2 · 3층, 완성 = 상륜부(Q41). 4등급이 석탑 구조와 맞고, 실제 국보(불국사 삼층석탑)와 같은 모양이 된다.
2. 칸 모양(빈칸 · 거친 돌 · 다듬은 돌 · 금동 돌 · 금 간 돌)은 학습 기록에서 계산하고 저장하지 않는다.
3. 장식(청사초롱 · 풍경 · 맨 위 돌 · 상륜부)은 가장 높은 값만 `cm:v1:tower`에 저장한다.
4. 장면은 한 판 끝 화면에서만, 2초 안에 1번. "움직임 줄이기"면 장면 없이 결과만.
5. 그림은 SVG 코드로 직접 그린다(외부 이미지 0개).

## 4. 결과 (Consequences)

- 좋은 점: 매 판 작은 보상이 생기고, 불안 · 착각의 뜻이 돌 모양으로 보여 다시 올 이유가 된다.
- 나쁜 점: 금동 돌(상자 8)은 문제마다 빨라도 119일이 걸려, 4주 검증 동안에는 거의 보이지 않는다. → 4주 안에 보이는 변화(거친 돌 → 다듬은 돌, 청사초롱 · 풍경)를 장면으로 충분히 보여 준다.
- 나쁜 점: 잘 알던 문제를 틀리면 돌이 내려가 속상할 수 있다. → "다시 맞히면 돌아와요" 1줄(AC-44s), 장식은 떼지 않는다.
- 나쁜 점: 석탑은 불교 문화재다. → 국보 · 문화유산으로 널리 알려진 모양이라 그대로 쓴다(사용자 확인, Q41). 다른 건축물은 두 번째 탑으로 남긴다(범위 밖, A16).
- 3D 단계(Q24)의 "함수 호출 탑"과 모양이 이어져, 다음 단계에서 같은 탑을 3D로 키울 수 있다.
