# ADR-0007: 파이썬 실행기(Pyodide)는 jsDelivr에서 버전을 고정해, 동의한 뒤에만 받는다

- 상태(Status): **채택(Accepted)** — 2026-11-25 설계(아키텍처 5-3b · 데이터 2-6 · 흐름 15장)와 함께 사용자 승인("승인")
- 날짜: 2026-11-25
- 결정한 사람: 프로젝트 오너(사용자)가 방향을 정함(요구 Q46~Q51). Claude가 구조를 제안.

## 1. 배경 (Context)

- 사용자가 이 계정이 닫히기 전(2026-11-28)에 파이썬까지 만들기를 원한다(Q46). 첫 범위는 파이썬 연습 4개로 끝까지 되는 모습이다(Q47).
- 브라우저에서 파이썬을 돌리려면 실행기(Pyodide)가 필요하다. 처음 받는 양은 압축 약 6.2MB다(2026-11-25 잼, 314.0.8).
- 이 게임은 지금까지 외부 라이브러리 0개 · 바깥 서버 연결 0곳(질문 보내기 제외)이었다(AC-72 · AC-03).
- 필드워드 사용자의 개인정보를 지켜야 한다(Q48 사용자 질문).

## 2. 선택지 (Options)

| 방법 | 개인정보 | 다시 올 때 속도 | 저장소 | 판단 |
|---|---|---|---|---|
| **A. jsDelivr에서 버전 고정해 받기 + 보호 4가지** | IP를 보는 곳이 1곳 늘지만, 동의한 사람만 · 파이썬을 열 때만 | 1년 캐시(`immutable`) | 가벼움 | ✅ 채택(Q48) |
| B. 저장소에 복사해 GitHub Pages로 | 바깥 곳이 늘지 않음(GitHub만) | 10분 캐시, 뒤에는 바뀌었는지 확인만 | 약 10MB가 Git 기록에 영원히 남음, MPL-2.0 라이선스 파일 필요 | ❌ |
| C. 파이썬을 서버에서 실행 | 코드 · 답이 서버로 감 | — | 서버 비용 · 관리 | ❌ 0원 · 서버 없음 원칙과 부딪힘 |

## 3. 결정 (Decision)

1. 실행기는 jsDelivr의 버전 고정 주소(`pyodide@314.0.8`)에서 받는다(AC-105).
2. 파이썬 연습을 열기 전에는 요청을 0번 보낸다(AC-100). 처음 열 때 사용자가 승인한 알림 문구로 묻고(AC-101), 동의는 1칸만 저장한다(AC-103). 안내 화면에서 언제든 끈다(AC-104).
3. 페이지에 `no-referrer`를 둬 게임 주소를 보내지 않는다(AC-106).
4. 실행기는 Web Worker(모듈 일꾼, `type: "module"`) 안에서만 돈다. Pyodide 314는 클래식 일꾼을 지원하지 않는다(2026-11-25 확인). 1초 상한은 ADR-0002와 같다. 켜 둔 일꾼을 다시 쓰고, 상한을 넘으면 일꾼째 멈춘다.
5. 동의하지 않거나 받지 못하면 미리 실행해 둔 출력으로 연습한다(AC-102 · 111).
6. "외부 라이브러리 0개" 원칙의 예외는 이 실행기 1개뿐이다. 파이썬 연습 코드도 표준 라이브러리만 쓴다.

## 4. 결과 (Consequences)

- 좋은 점: 0원. 자바스크립트만 하는 사람에게는 바깥 연결이 전혀 늘지 않는다. 저장소가 가벼워 공개 · 필드워드로 옮기기 부담이 적다.
- 나쁜 점: jsDelivr가 막힌 망(회사 등)에서는 파이썬 연습이 저장 출력으로만 된다. 실행기 버전을 올릴 때는 이 ADR을 대체하는 새 ADR과 함께 연습 4개를 다시 맞춘다.
- 검사 도구는 이 PC의 파이썬(3.12)으로 실행하고, 브라우저는 Pyodide(3.14)라 버전이 다르다(A17). 연습마다 브라우저에서도 실제로 맞춰 본다.
- jsDelivr 개인정보 처리방침(시행 2023-11-23, 2026-11-25 읽음)이 바뀌면 안내 문구를 다시 본다.
