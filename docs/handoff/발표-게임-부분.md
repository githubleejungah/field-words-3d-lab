- 쓴 때: 2026-11-25. 받는 곳: 필드워드를 맡은 Claude 계정(필드워드 발표 PPT를 만들 때 게임 부분의 정본으로 쓴다).
- 이 문서는 **발표에 넣을 내용**만 담는다. 숫자는 저장소에서 다시 확인한 값이다(2026-11-25 기준). 발표 날 다시 세어 고친다(아래 7장 명령).
- **발표 자료에는 추적 표시를 넣지 않는다**: 수용 기준 번호(AC-…), 결정 기록 번호(ADR-…), 질문 번호(Q…), 근거 기호((O) · (D) · (I))는 저장소 문서에만 둔다. 발표에서는 "요구를 문장 148개로 정리" 같은 개수만 쓴다.

## 1. 한 줄 소개

**코드 가려 보기**: 필드워드에서 익힌 IT 용어가 실제 코드에서 어떻게 쓰이는지, 코드 한 줄을 가리고 "그 줄이 없으면 무엇이 달라질까?"를 예측하며 읽는 연습 게임.

## 2. 왜 만들었나 (문제 → 해결)

| 문제 | 해결 |
|---|---|
| 용어 뜻은 외워도, 코드 속에서 그 용어가 무슨 일을 하는지는 모른다 | 용어마다 그 용어가 나오는 짧은 실무 코드(3~10줄)를 붙였다. 화면 위에 "이 코드 속 ○○" 칸으로 용어 비유와 코드 줄을 잇는다 |
| AI가 짜 준 코드를 "읽을" 수 있어야 검토 · 수정할 수 있다 | 코드를 쓰게 하지 않고 **읽게** 한다. 한 줄을 가리고 결과를 예측한 뒤 실제로 실행해 확인한다 |
| 맞혀도 찍은 건지 아는 건지 모른다 | 답하기 전에 **확신도**(확실해요 · 헷갈려요 · 몰라요)를 고른다. "확실했는데 틀림" = **착각**으로 따로 잡아, 고칠 때까지 다시 낸다 |
| 혼자 공부는 지루하고 쌓이는 게 안 보인다 | 문제 하나 = 돌 한 칸. 아는 정도에 따라 돌이 단단해져 **삼층석탑**이 쌓인다 |

## 3. 어떻게 하나 (한 판의 흐름)

1. **① 해석 보기**: [다음 줄 실행]으로 한 줄씩 실행하며 줄마다 조각 풀이 · 우리말 풀이 · 변수 상자 · 출력을 본다. 되풀이로 위 줄로 돌아가면 "↑ 되풀이라 3번 줄로 돌아왔어요"라고 알려 준다.
2. **② 가려 보기**: 한 줄을 가린다 → 확신도 → 보기 4개 중 출력 예측 → **실제로 실행**해 원래 코드와 가린 코드의 출력을 나란히 비교.
3. **③ 해석 고르기**: 그 줄이 하는 일을 보기 4개 중에서 고른다.
4. **결과**: 결과 뜻 1줄("이 문제는 4일 뒤에 다시 나와요") · 틀렸을 때 응원 1줄 · [자세히 보기](가린 코드를 줄마다 실제로 실행한 상자 값 표, "가린 줄은 ○○만 바꿔요" 요령).
5. **한 판 끝**: 석탑에 돌이 놓이거나 단단해지는 장면. 하루 목표를 채우면 청사초롱이 켜진다.

- 틀린 보기 하나하나가 **흔한 착각**을 겨냥한다. 예: `"5" + 3`은 8이다(실제 "53"), `sort()`는 숫자 순서다(실제 글자 순서), 객체를 `=`로 넣으면 복사본이 생긴다(실제 같은 것을 가리킴).

## 4. 근거 (학습 과학)

| 장치 | 근거 |
|---|---|
| 예측 → 실행 → 관찰 → 설명 | PRIMM(예측 · 실행 · 조사 · 수정 · 만들기) 코드 교육 방식 |
| 답을 보기 전에 먼저 예측 | 사전 시험 효과: 틀리더라도 먼저 답해 본 내용을 더 잘 기억한다 |
| 착각(확신했는데 틀림)을 따로 잡아 다시 풀기 | 과잉 교정 효과(Butterfield · Metcalfe 2001): 확신이 높았던 오답일수록 정답을 본 뒤 더 잘 고쳐진다 |
| 맞힐수록 다시 나오는 날이 멀어짐 | 간격 반복(라이트너 상자) — 필드워드와 같은 규칙 |
| 꾸밈은 끝 화면에만 | 유혹적 세부 효과: 푸는 중의 장식은 이해를 방해한다 |

## 6. 필드워드와 어떻게 이어지나

- **같은 도메인의 두 주소**: 필드워드 `…github.io/field-words/` → 메뉴 링크 → 게임 `…github.io/field-words-3d-lab/`(게임 저장소 공개 · 배포는 2026-11-25 사용자 결정 "A안", 공개 점검 보고서 승인 뒤).
- 게임은 필드워드 용어 사전(용어 이름 · 비유 · 약어 풀이)을 **읽기만** 한다. 필드워드 저장소와 학습 기록은 건드리지 않는다(기록 이름이 `cm:v1:*` · `fw:v1:*`로 달라 섞이지 않음).
- 같은 도메인이라, 검증 뒤 게임을 필드워드 안으로 옮겨도 학습 기록이 이어진다.
- 이야기 흐름 제안: **필드워드로 용어를 익힌다 → 게임에서 그 용어가 들어간 코드를 읽는다 → 실전 읽기 확인으로 실제 프로젝트 코드(리테일 챗봇)를 도움 없이 읽어 본다.**
